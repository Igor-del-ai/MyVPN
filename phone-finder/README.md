# Phone Finder — Telegram bot

Русскоязычный бот для справочной проверки телефонных номеров и формирования ссылок на публичные Telegram username.

## Возможности
- Проверка формата и валидности номера через libphonenumber.
- Страна/код региона, справочный регион, название оператора (если есть в базе), часовые пояса.
- Проверка синтаксиса Telegram username и ссылка на публичный профиль.
- Кнопочное меню на русском языке.

## Ограничения
Бот не определяет личность владельца номера, адрес или текущее местоположение. Telegram Bot API не раскрывает частные данные произвольных пользователей по username.

## Render
Blueprint находится в `render.yaml` в этой папке. Создайте Blueprint из ветки `phone-finder` и добавьте секрет `BOT_TOKEN` в настройках сервиса. Не публикуйте токен в репозитории.
